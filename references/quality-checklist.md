# 交付前检查清单与注意事项（Caveats）

## 交付前检查
- [ ] 每条 work 都有 `url`、`status`、`peer`、`checked`；随机抽 10% 重新打开链接核对标题/作者/日期/venue。
- [ ] 所有“已录用/发表”都查过官方渠道（出版社 DOI、会议论文集、DBLP、OpenReview）；仅作者自述的已标注。
- [ ] 公司博客、新闻、融资与估值数字都写明“公司自报 / 据某媒体报道”。
- [ ] 机构未核实的条目 `country` 留空，且在注意事项中列出。
- [ ] 计数口径（团队数、代表作数、香港等地区归属）写进“范围与方法”。
- [ ] GitHub 数据有抓取日期；自定义/非商用许可证已写进 `license_note`。
- [ ] `build.py --check` 无 error；`screenshot.py` 退出码 0，并逐张看过截图。
- [ ] 导出 `references.bib/.ris` 并在 Zotero 中试导入一次。
- [ ] 报告时间一律写明时区。

## 报告中应主动说明的局限
1. **收录偏差**：检索以英文、高影响力来源为主，可能低估非英语地区与小团队；地图与排名只反映样本。
2. **时效性**：预印本状态、星标、产品信息变化快；以核查日期为准。
3. **二手信息**：媒体解读和第三方博客的数字可能失真。
4. **分类主观性**：方向划分与主方向选择带有作者判断。
5. **地图边界**：Natural Earth 按“事实控制”绘制边界，不代表任何政治立场；正式出版需使用经审核的标准地图。
6. **自动化抓取的脆弱性**：HTML/Atom 回退解析依赖页面结构；API 规则（限速、是否需要 key）会变化。

## 不要做的事
- 不编造论文、作者、数字或链接；不把预印本写成“已发表”。
- 不抓取 Google Scholar；不绕过任何站点的限速或反爬验证。
- 不在报告里复制大段受版权保护的原文；摘要用自己的话写，并附链接。
